System Boundary and MVP Decisions

- Customers submit printing requests and documents, select services, and view request status and pickup information.
- Shop staff review requests, process printing, update status, and record payments made in person at pickup.
- Administrators manage users and printing-service options.
- Online payment, payment gateways, and delivery are outside the current MVP scope.
- Technology and deployment details marked provisional must be verified against the actual repository.
